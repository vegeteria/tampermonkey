# Tampermonkey Scripts

A collection of useful Tampermonkey scripts to bypass timers, auto-select links, and more.

## 🚀 Installation

Make sure you have a userscript manager installed like [Tampermonkey](https://www.tampermonkey.net/) before installing these scripts.

## 📦 Install All Scripts

Due to browser security restrictions, userscripts cannot be installed all at once via a single click. Please click the **Install** link for each script above that you wish to use.

## 🔄 Auto-Updates

All scripts have been configured with auto-update URLs. Tampermonkey will automatically check for updates periodically and prompt you to install them. If you want to force an update, you can check for updates manually in the Tampermonkey dashboard.
